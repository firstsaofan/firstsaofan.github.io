# 翻译站点

下面演示如何将 `docs/intro.md` 翻译成法语。

## 配置国际化

修改 `docusaurus.config.js`，为 `fr` 语言添加支持：

```js title="docusaurus.config.js"
export default {
  i18n: {
    defaultLocale: 'en',
    locales: ['en', 'fr'],
  },
};
```

## 翻译文档

将 `docs/intro.md` 复制到 `i18n/fr` 文件夹：

```bash
mkdir -p i18n/fr/docusaurus-plugin-content-docs/current/

cp docs/intro.md i18n/fr/docusaurus-plugin-content-docs/current/intro.md
```

然后将 `i18n/fr/docusaurus-plugin-content-docs/current/intro.md` 翻译成法语。

## 启动本地化站点

使用法语语言启动站点：

```bash
npm run start -- --locale fr
```

本地化站点可以通过 [http://localhost:3000/fr/](http://localhost:3000/fr/) 访问，`开始使用` 页面会被翻译。

:::caution

开发环境中一次只能使用一种语言。

:::

## 添加语言下拉菜单

为了在不同语言之间切换，添加语言下拉菜单。

修改 `docusaurus.config.js`：

```js title="docusaurus.config.js"
export default {
  themeConfig: {
    navbar: {
      items: [
        // highlight-start
        {
          type: 'localeDropdown',
        },
        // highlight-end
      ],
    },
  },
};
```

现在导航栏中会显示语言下拉菜单：

![语言下拉菜单](./img/localeDropdown.png)

## 构建本地化站点

为指定语言构建站点：

```bash
npm run build -- --locale fr
```

也可以一次构建所有语言：

```bash
npm run build
```

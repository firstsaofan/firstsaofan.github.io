# 播客

本页汇总 .NET 与软件工程相关的播客，全部免费收听。条目按来源仓库的原始顺序整理，未做主观排序。

:::info
本节内容整理自源仓库 `podcasts.md`（快照日期 2026-10-25）。原清单共 8 个播客，全部保留；链接已经逐一实测。停更或长期未更新的条目在说明中标注。
:::

## .NET 与软件工程播客

1. [.NET Rocks](https://www.dotnetrocks.com/)
   Carl Franklin 与 Richard Campbell 主持的 .NET 老牌播客，1900+ 期，覆盖从语言内部机制到职业建议的 .NET 生态各个角落。仍在更新。

2. [Merge Conflict](https://www.mergeconflict.fm/)
   Frank Krueger 与 James Montemagno 的周更播客，话题覆盖 .NET、MAUI、移动开发以及更广泛的软件世界。仍在更新。

3. [No Dogma Podcast](https://nodogmapodcast.bryanhogan.net/)
   Bryan Hogan 访谈 .NET 开发者与架构师，讨论真实世界的软件设计决策与职业成长。域名已实测可用，仍在更新。

4. [The .NET Core Podcast](https://dotnetcore.show/)
   Jamie Taylor 主持，2018 年开播至今，专攻 .NET Core / .NET 5+，访谈正在构建真实 .NET 应用的社区成员。仍在更新。

5. [Coding Blocks](https://www.codingblocks.net/)
   讨论式播客，话题覆盖最佳实践、设计模式、架构与开发者效率。
   **注：已于 2024 年 10 月停更**，最后一期为第 242 期。历史 242 期内容仍可收听，适合按主题回听。

6. [Adventures in .NET](https://topenddevs.com/podcasts/adventures-in-net)
   圆桌与访谈形式，话题从 Web API 到桌面开发再到云服务。
   **注：最后一期为 2024 年 11 月的第 206 期**，此后未更新。历史内容仍可收听。

7. [Software Engineering Radio](https://se-radio.net/)
   不限于 .NET，由 IEEE Computer Society 与 IEEE Software 杂志出品，2006 年开播的资深工程师长谈，话题覆盖架构、分布式系统与工程实践。仍在更新。

8. [Programming Throwdown](https://www.programmingthrowdown.com/)
   Patrick Wheeler 与 Jason Gauci 主持，每期一个语言或技术主题，经常涉及 .NET 与 C#。仍在更新。

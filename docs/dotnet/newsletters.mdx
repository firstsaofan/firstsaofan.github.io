## 带代码深挖

包含代码片段、面向 C# 与 .NET 的技术深挖。

1. [Stefan Djokic](https://stefandjokic.tech/)
   周更 newsletter，讨论 C# 与 .NET 的初中高级话题，也涉及设计模式。

2. [Milan Jovanovic](https://milanjovanovic.tech/)
   The .NET Weekly，每周六一封，用易懂的方式讲清 C# 与 .NET 的复杂话题，也覆盖 Clean Architecture、CQRS 与软件设计。

3. [Muhammad Waseem](https://mwaseemzakir.com/)
   The .NET Saturday Newsletter，每周一封，覆盖 ASP.NET Core、EF Core、Azure 与架构决策。作者站内另有免费视频、面试题与 "30 .NET Tips" 电子书入口。

4. [Julio Casal](https://juliocasal.com/)
   周更 newsletter，话题覆盖 C#/.NET/Docker，也涉及微服务。站内另有免费的 .NET 后端路线图。

5. [Andrew Lock](https://andrewlock.net/)
   ASP.NET Core 内部机制、中间件与高级 .NET 特性的深挖。站点在页脚提供邮件订阅入口，也可用 RSS。

6. [Khalid Abuhakmeh](https://khalidabuhakmeh.com/)
   JetBrains 开发者倡导者，分享 .NET 技巧、Rider 特性与开源发现。

4. [Byte Byte Go](https://blog.bytebytego.com/)
   面向系统设计能力提升的周更 newsletter，以图文讲解复杂系统著称。

5. [Tech World with Milan](https://newsletter.techworld-with-milan.com/)
   面向工程师、架构师与工程管理者的技术周更，话题含工程判断力、软件架构与 AI。

6. [The Pragmatic Engineer](https://newsletter.pragmaticengineer.com/)

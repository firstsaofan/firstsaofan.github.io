# 会议

本页汇总 .NET 与 C# 相关的主要会议，以及可免费观看录播的线上活动入口。

:::info
本节内容整理自源仓库 `conferences.md`（快照日期 2026-10-25），分为年度会议与线上/按需两部分，全部保留。链接均已逐一实测。
:::

## 年度会议

1. [.NET Conf](https://www.dotnetconf.net/)
   由微软与 .NET 社区主办的免费线上社区活动，覆盖 .NET、C#、ASP.NET 等最新特性。每年 11 月随 .NET 发布举行。

2. [NDC Conferences](https://ndcconferences.com/)
   NDC（Norwegian Developers Conference）在奥斯陆、伦敦、悉尼和波尔图举办，是最佳软件会议之一，.NET、架构与工程内容扎实。

3. [Microsoft Build](https://build.microsoft.com/)
   微软年度开发者大会，发布 .NET、Azure、AI 与全部微软技术的公告与会议演讲。

4. [CodeMash](https://www.codemash.org/)
   在美国俄亥俄州 Sandusky 举办的多学科技术会议，有较强的 .NET 板块，同时覆盖 Web、移动、云等话题。

5. [DotNext](https://dotnext.ru/)
   专攻 .NET 及相关技术的会议，覆盖性能、内部机制、新语言特性与真实实践。

6. [Techorama](https://www.techorama.be/)
   在比利时与荷兰举办的技术会议，.NET、Azure 与微软生态覆盖出色。

7. [Update Conference Prague](https://www.updateconference.net/)
   在布拉格举办的微软技术向开发者会议，.NET 与 Azure 内容扎实。

## 线上 / 按需

1. [JetBrains .NET Days Online](https://www.jetbrains.com/dotnet/)
   JetBrains 主办的免费线上会议，聚焦 .NET 开发工具、Rider 与最佳实践。历年录播可在 YouTube 观看。

2. [Microsoft Learn Events](https://learn.microsoft.com/en-us/events/)
   微软官方全年提供的按需与直播课程，覆盖全部 .NET 话题。

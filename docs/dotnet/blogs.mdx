# 博客

本页汇总 .NET 领域的高质量博客站点，按来源仓库的原始顺序整理，未做主观排序。所有站点均可免费阅读。

:::info
本节内容整理自源仓库 `blogs.md`（快照日期 2026-10-25），共 26 个博客站点，另含系统设计方向条目。原清单被截断只读到 15 个，本次已拉取完整版。链接均已逐一实测；个别站点域名变更或已废弃，在说明中标注。
:::

## .NET 与 C# 博客

1. [Code4IT](https://www.code4it.dev/)
   Davide Bellone 的博客，几乎覆盖 C# 从基础到高级的全部话题，适合打基础。仍在更新。

2. [Andrew Lock](https://andrewlock.net/)
   以《ASP.NET Core in Action》闻名，产出覆盖 C# 与 .NET 各领域的深度文章。仍在更新。

3. [Code Maze](https://code-maze.com/)
   .NET 教程体系最完整的站点之一，ASP.NET Core、EF Core、Blazor、设计模式等都有成系列免费教程。仍在更新。

4. [.NET Tricks](https://www.dotnettricks.com/)
   覆盖 .NET 及其他语言的书籍、课程与演讲。**注：原域名现已跳转到 `scholarhat.com`**，站点仍可访问，内容以课程为主。

5. ~~Method Poet~~（域名已失效）
   原地址 `methodpoet.com` 已无法访问，域名被第三方占用。**建议从本清单移除。**

6. [Josip Miskovic](https://josipmisko.com/)
   C# 与 .NET 基础及 Web 开发的实践教程，也有软件评测与职业发展内容。

7. [.NET Tutorials](https://dotnettutorials.net/)
   MVC、C#、Web API、设计模式与 .NET 的系统教程，也覆盖 Java、Python、C/C++。站点自述全部教程免费。

8. [Code with Mukesh](https://codewithmukesh.com/)
   Mukesh 的博客，聚焦 Azure、AWS、C# 与 .NET 的实践教程，2015 年写作至今。站点自述全部内容免费阅读，另有免费课程与 newsletter。

9. [Steve Smith (Ardalis)](https://ardalis.com/blog/)
   .NET 领域知名架构师，聚焦架构、整洁代码与设计模式。站点另有免费的架构与云原生电子书入口。仍在更新。

10. [Coding Sonata](https://codingsonata.com/)
    Aram Tchekrekjian 的博客，C# 与 .NET 文章结构清晰，也有 newsletter 订阅。仍在更新。

11. [Dave Callan](https://davecallan.com/)
    以 C# 基准测试和 Visual Studio 实用技巧著称，450+ 篇文章覆盖 Azure、C#、EF 与 .NET。

12. [Milan Jovanovic](https://milanjovanovic.tech/)
    高级 C# 与 .NET 话题——Clean Architecture、CQRS 与软件设计。站点即 The .NET Weekly newsletter 的归档。

13. [Julio Casal](https://juliocasal.com/)
    覆盖 .NET 基础与高级话题，包括 Docker 与微服务。站内有免费的 .NET 后端路线图。

14. [Stefan Djokic](https://stefandjokic.tech/)
    基础与高级 C#/.NET 话题与设计模式。

15. [Stevan Giesel](https://steven-giesel.com/)
    来自苏黎世的 .NET 开发者，专注高级 .NET 话题，博客源码开源在 GitHub。仍在更新。

16. [Steve Gordon](https://www.stevejgordon.co.uk/)
    Microsoft MVP、Elastic 高级工程师，专注 ASP.NET Core 内部机制、性能与 HTTP。

17. [Dan Patrascu-Baba](https://danpatrascu.com/)
    开发者与 .NET 培训师，聚焦 Microsoft Cloud、Office 365 与 Azure。现为 Atherio 联合创始人兼 CTO，博客更新频率降低。

18. [Code to Solutions](https://codetosolutions.com/)
    覆盖 ASP.NET Core、Web API、MVC、C#、Entity Framework、Angular、AWS 与 SQL Server，配可运行的代码示例。

19. [Stephen Cleary](https://blog.stephencleary.com/)
    Microsoft MVP，《Concurrency in C# Cookbook》作者。async/await、Task 与并发话题的权威参考，写生产级异步代码前必读。

20. [Elmah.io Blog](https://blog.elmah.io/)
    elmah.io 是 .NET Web 应用的错误日志服务，其博客覆盖 .NET、C# 与 Web 开发话题。仍在更新。

21. [Code Guru](https://www.codeguru.com/)
    覆盖 Microsoft 相关软件开发、移动、数据库与 Web 应用编程。站点有 Cloudflare 防护，直接访问可能返回 403。

22. [Rahul Nath](https://www.rahulpnath.com/blog/)
    开发者、YouTuber 与博主，清晰实用地讲解 C#、.NET 与 Azure，480+ 篇文章。

23. [Rmauro Dev](https://rmauro.dev)
    构建稳健、可扩展、安全 Web 应用的技巧与见解，覆盖 C# 与 Azure，也有自托管与本地 LLM 话题。

24. [Scott Hanselman](https://www.hanselman.com/blog/)
    Microsoft 合作伙伴项目经理与开发者倡导者，覆盖 .NET、开发者工具、生产力与技术泛主题。仍在更新。

25. [Mark Seemann (ploeh)](https://blog.ploeh.dk/)
    函数式 C#、依赖注入模式、TDD 与软件设计专家，长文思考深入。仍在更新。

26. [Khalid Abuhakmeh](https://khalidabuhakmeh.com/)
    JetBrains 开发者倡导者，撰写 .NET、Rider、实践开发技巧与开源项目，383 篇文章。

# 任务与技能协作

任务大厅和技能市场是用户之间的信息与协作入口。平台不代收资金、不托管交付、不保证履约，也不替代用户自行完成沟通、验收和争议处理。

## 任务大厅

### 查找任务

进入任务大厅后，可以按关键词、分类、地区、状态、预算、远程和长期合作等条件筛选。关闭“远程”或“长期合作”开关表示“不限制”。

打开任务详情后，先确认：

- 任务描述和交付范围；
- 预算和截止时间；
- 地区、远程条件和合作期限；
- 发布人和联系方式；
- 当前任务状态。

确认适合且愿意承担后，再点击“接取任务”，并通过页面提供的联系方式与发布人确认细节。

### 发布任务

1. 登录后点击“发布任务”。
2. 填写标题、描述、分类、地区、预算区间、截止时间和联系方式。
3. 选择是否支持远程、是否长期合作、预算是否可协商，并填写联系人称呼。
4. 确认内容真实、完整且联系方式可被正常查看后发布。

源文档记录的要求如下，实际以当前页面提示为准：

| 内容 | 要求 |
| --- | --- |
| 标题 | 至少 5 字，最多 30 字 |
| 描述 | 至少 20 字，最多 2000 字 |
| 分类、截止时间、联系方式 | 必填 |
| 截止时间 | 必须晚于当前时间 |
| 地区 | 最多 100 字 |
| 联系方式、联系人称呼 | 分别最多 500 字、50 字 |
| 预算 | 不能为负数，上限不能低于下限 |

任务发布后需要审核，当前没有任务草稿入口。

### 接取、完成与取消

当前流程中，任务处于“已发布”且发布者不是本人时可以点击“接取任务”。接取是直接操作，没有申请理由、报价、发布者审批或等待确认步骤。

只有任务发布人且任务处于“已接取”状态时，页面才会显示“标记完成”。承接人没有单独的站内验收确认流程，双方应提前约定交付和验收方式。

发布人或承接人都可以取消接取；取消后任务回到“已发布”。删除仅适用于可删除的已发布任务，并且删除后不可恢复。

### 评价与投诉

任务完成后，任务发布人或承接人可以提交一次 1–5 星评价，内容至少 2 字。评价需要审核后才展示，同一用户不能重复评价同一任务。

如遇虚假任务、骚扰、诈骗嫌疑或其他违规行为，可以在任务详情发起投诉，并在“我的投诉”查看进度。投诉描述应客观、具体，只提供处理问题所需的证据。

## 技能市场

### 发布技能名片

1. 登录后进入“技能市场”，点击“发布技能名片”。
2. 填写展示昵称、个人简介、技能标签、擅长方向、可工作时间、报价区间、联系方式和作品集链接。
3. 选择所在地区和是否接受远程。
4. 提交审核，在“我的技能”查看状态。

源文档记录的要求包括：

- 展示昵称至少 2 字；
- 个人简介至少 20 字；
- 技能标签为 1–10 个；
- 联系方式必填；
- 作品集链接最多 10 个。

每个用户只能拥有一张技能名片；已有名片时应编辑原名片。名片主人可以暂停或恢复承接，暂停不会删除名片或自动隐藏名片。

当前技能市场不提供站内私信、委托申请、订单、报价确认、技能收藏或独立技能评价流程。访客可以查看或复制联系方式，委托、付款、交付、知识产权和争议由双方自行处理。

## 协作安全

- 接取任务或联系技能服务者前，先核实身份、内容、费用、交付和付款方式。
- 不要预付用途不明的大额款项。
- 不要提供密码、验证码、远程控制权限或不必要的个人证件。
- 不要在正文、评论或投诉中公开他人的敏感资料。
- 平台内的等级、头衔和身份标签不等于认证、担保或履约保证。

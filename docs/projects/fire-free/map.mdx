# 生活地图

生活地图用于帮助用户缩小生活地点的探索范围。地图展示的是可核对的地区信息和用户经验，不是城市评分、推荐榜或投资建议。

## 搜索地区

1. 点击顶部导航或首页中的“生活地图”。
2. 在搜索框输入完整的城市名或省份名，例如“杭州”或“河南省”。
3. 等待地图定位并高亮已收录地区。
4. 点击省份进入省级视图，再点击目标城市打开地区详情。
5. 点击“全国”返回全国视图。

搜索更接近完整行政区名称匹配。出现“暂未收录数据”表示行政区存在，但平台暂时没有该地区资料；这不代表该地区不适合。

## 地图颜色

| 颜色 | 含义 |
| --- | --- |
| 青绿色 | 已收录，或命中当前筛选条件 |
| 浅青色 | 已收录，但没有命中当前筛选条件 |
| 灰色 | 暂未收录数据，不代表地区不适合 |

地图颜色不是城市排名或推荐。

## 使用筛选器

在“我的筛选器”区域可以新建、保存、启用、停用、编辑或删除筛选器。筛选维度包括：

- 整租月租上下界；
- 二手房均价、上车盘总价和估算月生活支出；
- 空气优良天数、夏冬平均气温和相对湿度；
- 常住人口；
- 火车站、机场和地铁等交通设施；
- 用户经验、医院等级、气候场景、城市类型和省份。

官方模板可能包括“极简生存”“兼职友好”“品质生活”和“远程办公”等。模板只是预填条件，不代表平台推荐的城市名单。

筛选结果只会匹配具备相应数据字段的地区。缺失字段显示“待完善”，对缺失字段设置数值条件可能得到 0 个结果。筛选器保存在当前浏览器设备中，不属于云端同步功能。

## 地区详情与数据来源

地区详情可能包含：

- 地区名称、所属省份、简介和更新时间；
- 整租、二手房和月生活支出；
- 空气、气温、湿度、医院、设施和人口信息；
- 数据来源、统计口径和采集日期；
- FIRE 社区与用户经验。

数据可能因来源、采集时间、统计口径和样本不同而存在差异。作出迁居、租房、购房或投资决定前，应通过可靠渠道再次核实。

## 提交地区客观数据

1. 在地图页点击“提交地区数据（需审核）”并登录。
2. 搜索并选择要提交的行政区。
3. 填写地区介绍和地区级别。
4. 至少填写一项客观指标。
5. 填写来源名称、来源类型、采集时间和统计口径。
6. 如有来源链接，按页面要求填写有效的 `http://` 或 `https://` 链接。
7. 提交后，在“我的提交”中查看审核状态。

不要编造数据，也不要把个人感受当作客观统计。被驳回后，应根据页面显示的原因修正再提交。没有把握的数据可以暂不填写。

## 经验帖与社区信息

地区经验帖和社区信息主要由用户提交，属于非官方内容。平台展示不代表对真实性、适用性或安全性作出保证。请将经验帖与客观数据分开理解，并在重要决定前自行核实。

# 快速开始

本页面向第一次访问 FIRE自由 的用户。建议先浏览公开内容，再决定是否注册和参与互动。

## 先逛一逛

第一次打开网站时，可以先查看以下入口：

1. **文章**：阅读其他人的 FIRE 实践、经验和复盘。
2. **生活地图**：了解不同地区的生活成本、环境和已收录数据。
3. **FIRE 路径**：查看自己认同或想参考的生活方式。
4. **社区**：看看大家正在讨论什么。

文章、地图、任务、技能和社区的大部分公开内容可以先浏览。遇到点赞、收藏、评论、发布或提交资料等操作时，再注册账号。

## 注册账号

1. 点击右上角“注册”。
2. 填写用户名、常用邮箱、邮箱验证码和密码。
3. 手机号为选填项；按照页面提示完成注册。
4. 注册成功后进入个人主页，按需设置头像、昵称和个人简介。

源教程中的字段限制如下，实际以注册页面提示为准：

- 用户名由 3–20 位字母、数字或下划线组成，注册后不能修改。
- 邮箱验证码具有页面显示的有效期。
- 建议使用至少 8 位且不全是数字的密码。
- 不要与他人共享账号、密码或验证码。

## 确定当前目标

不需要一开始就决定以后一定在哪里生活，可以先选择一个当前目标：

- 想找地方生活：先使用[生活地图](./map.mdx)。
- 想看真实经验：先阅读文章和社区内容。
- 想找人做小事或提供帮助：查看任务大厅和技能市场。
- 想记录自己的实践：完善资料并发布文章或帖子。

## 完成第一次互动

在一篇文章或帖子详情页登录后，可以先完成一个动作：

- 点赞；
- 收藏；
- 发表评论。

熟悉个人中心后，再尝试发布内容或参与协作。内容提交成功不一定代表已经公开展示，请到对应的“我的…”页面查看审核状态。

## 第一次使用路线

推荐按以下顺序体验：

1. 阅读一篇 FIRE 文章并收藏它。
2. 在生活地图中搜索一个城市，查看数据来源。
3. 浏览一个感兴趣的 FIRE 路径。
4. 在社区留下一个包含具体背景的问题或经验。
5. 完善昵称、头像和个人简介；公开财务信息前检查隐私设置。
6. 如有需要，再浏览任务大厅或技能市场。

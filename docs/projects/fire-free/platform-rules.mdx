# 平台规则

本规则是使用本站的前提条件。参与平台即表示您已阅读并同意遵守本规则；如不同意，请停止发布或互动内容。

## 适用范围

本规则适用于用户在 FIRE自由 发布的文章、帖子、评论、标签、头像、个人资料、地区数据、地区经验、任务、技能名片、投诉和意见箱内容，也适用于用户之间的互动行为。

平台鼓励真实、具体、可验证的信息分享。本规则与[免责声明](./disclaimer.mdx)配套阅读：本规则说明什么能做、什么不能做，免责声明说明风险由谁承担。两者冲突时，以适用法律为准。

## 账号与身份

- 一个用户应使用本人账号，不得恶意注册、批量注册、共享、出租或出售账号。
- 不得利用自动化脚本、机器人、批量抓取或其他技术手段绕过审核、限制访问或干扰平台运行。
- 不得冒充平台工作人员、管理员、路径管理人员、媒体、名人或其他个人或机构。
- 不得通过头像、昵称、头衔、等级、网站或资料内容误导他人相信其具有某种身份、资质或授权。
- 不得使用虚假头像、经历、资质、联系方式或他人身份信息；资料应尽量真实、准确且可正常联系。
- 联系方式变更或账号异常时，应及时通过正式渠道更新或反馈。
- 公开实践档案前，应审慎决定是否展示城市、收入来源和月均支出等可能涉及隐私的信息。

## 内容真实性与来源

- 用户应对自己发布的内容负责，不得编造、夸大、抄袭或故意传播虚假信息。
- 分享他人的文章、数据、视频、截图、案例或观点时，应说明来源，并在适用情况下取得授权。
- 地区客观数据应填写来源名称、来源类型、采集时间和统计口径；没有可靠来源时，不应编造数据。
- 个人体验、推测和建议必须与客观数据区分，不得包装为官方结论、排名或保证。
- 政策、规则、数据和法律信息可能变化，应以最新权威来源为准。

## 禁止发布的内容

平台禁止违法违规、侵权、欺诈、恶意或高风险内容，包括但不限于：

- 违反适用法律法规的内容；
- 诈骗、钓鱼、虚假中奖、刷单、传销、非法集资或其他欺骗性内容；
- 恶意传播病毒、木马、攻击代码或用于违法目的的技术教程；
- 色情、露骨性内容、未成年人性内容、性暴力或其他剥削性内容；
- 仇恨、歧视、骚扰、威胁、暴力、自伤鼓励或煽动现实伤害的内容；
- 侵犯著作权、商标权、肖像权、隐私权、商业秘密或其他合法权益的内容；
- 未经同意公开他人的身份证件、手机号、住址、财务记录、病历或聊天记录；
- 冒充他人、虚构身份、伪造交易、评价、经历、数据、来源或官方通知；
- 垃圾广告、重复内容、恶意刷屏、无关导流、未经允许的商业推广或诱导私下交易；
- 账号密码、验证码、密钥、后台地址或其他敏感系统信息；
- 任何可能危害平台、用户或第三方网络安全、系统稳定或合法权益的行为。

## 账号名称、头像与头衔

- 昵称、用户名、头像和头衔不得冒充官方身份，也不得包含违法、歧视、侮辱、侵权和误导性内容。
- 不得擅自使用与平台、合作机构、媒体或知名人士高度近似的名称、头像和头衔造成混淆。
- 等级与头衔仅用于展示，不构成平台认证、专业能力证明、推荐权重、收益承诺或交易担保。
- 头衔被撤销、过期或不再适合展示时，平台可要求停止佩戴或公开展示。

等级头衔的获得口径、自定义头衔的来源与佩戴规则，以及昵称旁标签颜色的含义，见[等级与头衔](./titles.mdx)。

## 互动与讨论

- 评论和讨论应围绕主题，避免人身攻击、羞辱、威胁、骚扰、刷屏和无关争吵。
- 对不同观点应使用可验证信息和理性表达，不以举报、围攻或批量回复代替讨论。
- 不得冒充他人发表评论，不得伪造不存在的经历、交易、评价或互动。
- 引用他人内容时应尊重上下文，不故意歪曲、截取或煽动攻击。
- 在专业、法律、财务、医疗等领域分享内容时，应说明其局限，不应将个人经验包装成权威结论。

## 地图数据与地区内容

- 不得编造地区数据、统计来源、采集时间、行政区划、设施或用户经验。
- 不得以筛选结果、地图颜色、地区列表或用户观点宣称平台对地区进行评分、排名或推荐。
- 提交客观数据时，应遵守字段要求并提供足够来源信息。
- 不得利用地图或地区信息从事骚扰、跟踪、歧视、欺诈、非法测绘或其他违法行为。
- 用户经验属于非官方内容，平台展示不代表对其真实性、适用性或安全性作出保证。

## 任务大厅规则

任务大厅是信息展示与用户协作入口，不是支付、托管或担保交易平台。

- 任务发布者应提供真实、清晰、合法、可交付的任务信息，并如实说明预算、期限和条件。
- 禁止发布虚假任务、诈骗、刷单、非法服务、骚扰、歧视、侵权或其他违法违规任务。
- 承接者不得擅自转交任务、伪造进度或提交与任务约定不符的成果。
- 双方应自行确认工作范围、费用、支付、交付、验收、保密和知识产权安排。
- 平台不代收任务款、不托管交付、不保证履约，也不替代双方自行解决争议。
- 不得利用任务信息、联系方式或历史交易实施骚扰、诈骗、报复或侵犯隐私。

## 技能市场规则

- 技能名片中的技能、经历、资质、报价、可工作时间、地区和联系方式应由本人提供，并保持真实。
- 不得使用技能市场发布诈骗、刷单、非法服务、恶意引流、虚假评价或侵犯他人权益的内容。
- 每个用户应遵守平台关于名片数量、承接状态和内容维护的限制。
- 「暂停承接」仅表示暂不接受新委托，不代表名片被平台认证或担保。
- 委托、付款、交付、知识产权和争议由双方自行处理，平台不构成中介、担保或裁判方。

## 隐私与敏感信息

- 不得在公开内容中发布他人的敏感个人信息或未经同意的聊天、交易和身份资料。
- 发布自己的财务实践信息前，应评估公开范围和潜在风险。
- 不得利用投诉、评论或其他站内功能骚扰他人、反复传播其隐私或实施报复。
- 投诉证据应仅包含处理问题所必需的内容，并遮挡无关敏感信息。
- 发现账号、邮箱或联系方式被盗用时，应及时修改密码并通过正式渠道反馈。

## 知识产权

- 用户应确保发布内容为原创、已获授权或属于依法可使用的内容。
- 未经许可，不得复制、改编或传播他人的文章、图片、视频、课程、数据、商标或个人信息。
- 引用内容时应注明合理来源；涉及合理使用、转载和商业使用时，应遵守适用规则。
- 发生知识产权争议时，平台可在核实风险后采取限制展示、删除内容或暂停相关账号等措施。
- 平台不因提供展示、存储、搜索或分类功能而放弃对合法权利人的权利保护。

## 商业推广与外部导流

- 与任务、技能或个人服务相关的内容应真实说明关系和目的，不得伪装成普通经验分享。
- 未经平台允许，不得在公开内容中批量发布广告、重复导流、诱导站外交易或规避审核。
- 发布外部链接前，应确认链接安全、真实且与内容相关。
- 不得通过外部链接收集与平台服务无关的敏感信息，或诱导用户绕过平台安全提示。

## 投诉、举报与反馈

- 投诉应针对具体行为，客观描述事实并提供必要证据，不得恶意诬告、刷投诉或扩大无关隐私。
- 意见箱用于功能建议和 Bug 反馈，不应替代面向具体违规行为的投诉。
- 同一人重复提交、明显不实或无法核实的投诉，可能不被受理。
- 不得因投诉、举报或提供证据而威胁、骚扰或报复相关人员。

## 违规处置

平台可根据违规行为的性质、严重程度、影响范围、历史情况、风险和适用规则采取：

- 内容提示或补充说明；
- 限制内容展示或互动；
- 删除违规内容；
- 暂停或限制相关功能；
- 暂停、限制或封禁账号；
- 配合处理投诉、权利争议和安全风险；
- 其他为保护平台、用户或公众利益所必要的措施。

处理前应尽量核实事实、区分主观恶意与无意失误，并遵循与违规程度相称的原则。平台不对处理方式、处理时限或处理结果作超出实际能力的承诺，具体案件不预先承诺固定处罚、时限或结果。

## 规则更新与联系

平台可能根据产品变化、运营需要、安全事件或适用要求更新本规则。更新后的规则将在站内文章中发布并标注日期，重大变化将通过站内显著方式提示。继续使用或发布内容，即表示用户已阅读更新后的规则。平台不会通过本规则排除适用法律赋予用户的权利。

| 情形 | 渠道 |
| --- | --- |
| 对规则有疑问、功能建议、Bug 反馈 | 登录后进入「意见箱」 |
| 发现任务或技能相关违规 | 在对应详情页发起投诉 |
| 查看投诉处理进度 | 「我的投诉」 |
| 账号安全、隐私与数据权利、正式书面函件 | 运营者邮箱（待补充） |

请勿在意见箱、投诉或公开内容中提交密码、验证码、身份证号、银行卡号等敏感信息。

本站没有在线客服，也没有独立帮助中心。这是个人运营的站点，反馈会看，但请理解处理可能需要时间。规则相关问题请通过上述渠道提出，运营者会尽力解答并在必要时修订本文档。相关内容可参见[关于本站](./about.mdx)。

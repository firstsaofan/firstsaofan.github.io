# 平台规则

:::caution
本页根据源文档整理，源文档标注为“运营发布草稿”。正式发布前，平台运营方应结合实际审核能力、处置流程和适用法律完成复核。
:::

## 适用范围

本规则适用于用户在 FIRE自由 发布的文章、帖子、评论、标签、头像、个人资料、地区数据、地区经验、任务、技能名片、投诉和意见箱内容，也适用于用户之间的互动行为。

平台鼓励真实、具体、可验证的信息分享。参与平台即表示用户已阅读并同意遵守本规则；如不同意，请停止发布或互动内容。

## 账号与身份

- 一个用户应使用本人账号，不得恶意注册、批量注册、共享、出租或出售账号。
- 不得利用自动化脚本、机器人或批量抓取绕过审核、限制访问或干扰平台运行。
- 不得冒充平台工作人员、管理员、媒体、名人或其他个人或机构。
- 不得使用虚假头像、经历、资质、联系方式或他人身份信息。
- 公开实践档案前，应审慎决定是否展示城市、收入来源和月均支出等隐私信息。

## 内容真实性与来源

- 用户应对自己发布的内容负责，不得编造、夸大、抄袭或故意传播虚假信息。
- 分享他人的文章、数据、视频、截图、案例或观点时，应说明来源，并在适用情况下取得授权。
- 地区客观数据应填写来源名称、来源类型、采集时间和统计口径。
- 个人体验、推测和建议必须与客观数据区分，不得包装为官方结论、排名或保证。
- 政策、规则、数据和法律信息可能变化，应以最新权威来源为准。

## 禁止发布的内容

平台禁止违法违规、侵权、欺诈、恶意或高风险内容，包括但不限于：

- 诈骗、钓鱼、虚假中奖、刷单、传销或非法集资；
- 恶意传播病毒、木马、攻击代码或违法技术教程；
- 色情、露骨性内容、未成年人性内容、性暴力或剥削性内容；
- 仇恨、歧视、骚扰、威胁、暴力、自伤鼓励或煽动现实伤害；
- 侵犯著作权、商标权、肖像权、隐私权、商业秘密或其他合法权益；
- 未经同意公开他人的身份证件、手机号、住址、财务记录、病历或聊天记录；
- 冒充他人、虚构身份、伪造交易、评价、经历、数据、来源或官方通知；
- 垃圾广告、重复内容、恶意刷屏、无关导流或诱导私下交易；
- 账号密码、验证码、密钥、后台地址或其他敏感系统信息；
- 危害平台、用户或第三方网络安全、系统稳定或合法权益的行为。

## 互动与讨论

评论和讨论应围绕主题，避免人身攻击、羞辱、威胁、骚扰、刷屏和无关争吵。引用他人内容时应尊重上下文，不故意歪曲、截取或煽动攻击。在专业、法律、财务、医疗等领域分享内容时，应说明局限，不应将个人经验包装成权威结论。

## 地图数据与地区内容

- 不得编造地区数据、统计来源、采集时间、行政区划、设施或用户经验。
- 不得以地图颜色、筛选结果、地区列表或用户观点宣称平台进行评分、排名或推荐。
- 提交客观数据时，应遵守字段要求并提供足够来源信息。
- 不得利用地图或地区信息从事骚扰、跟踪、歧视、欺诈、非法测绘或其他违法行为。
- 用户经验属于非官方内容，平台展示不代表对其真实性或适用性作出保证。

## 任务大厅与技能市场

任务大厅是信息展示与用户协作入口，不是支付、托管或担保交易平台。任务发布者和承接者应自行确认工作范围、费用、支付、交付、验收、保密和知识产权安排。

技能名片中的技能、经历、资质、报价、时间和联系方式应由本人提供并保持真实。技能市场展示不代表平台对身份、资质、作品、报价或服务能力作出认证或担保。

## 隐私、敏感信息与知识产权

- 不得在公开内容中发布他人的敏感个人信息或未经同意的聊天、交易和身份资料。
- 发布自己的财务实践信息前，应评估公开范围和潜在风险。
- 投诉证据应只包含处理问题所必需的内容，并遮挡无关敏感信息。
- 用户应确保发布内容为原创、已获授权或属于依法可使用的内容。
- 未经许可，不得复制、改编或传播他人的文章、图片、视频、课程、数据、商标或个人信息。

## 商业推广与外部导流

商业推广应真实说明关系和目的，不得伪装成普通经验分享。不得批量发布广告、重复导流、诱导站外交易或规避审核。发布外部链接前，应确认链接安全、真实且与内容相关。

## 投诉、反馈与违规处置

投诉应针对具体行为，客观描述事实并提供必要证据。意见箱用于功能建议和 Bug 反馈，不替代针对具体违规行为的投诉。

平台可根据违规性质、严重程度、影响范围、历史情况、风险和适用规则采取内容提示、限制展示、删除内容、暂停互动、暂停功能、限制或封禁账号等必要措施。处理前应尽量核实事实，并遵循与违规程度相称的原则；具体案件不承诺固定处罚、时限或结果。

## 规则更新与反馈

规则可能根据产品变化、运营需要、安全事件或适用要求更新。更新后的规则将在站内文章中发布并标注日期；重大变化将通过站内显著方式提示。

对规则有疑问、发现违规或需要反馈 Bug，可登录后通过“意见箱”提交。涉及任务或技能的具体违规，请在相应详情页发起投诉，并在“我的投诉”查看状态。

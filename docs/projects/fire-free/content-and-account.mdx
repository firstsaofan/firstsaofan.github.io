# 内容与个人中心

## 文章与社区帖子

文章适合完整的实践复盘、教程或长期整理的经验；社区帖子适合问题、讨论、求助和短期分享。两者通常都需要审核。

### 发布文章

1. 登录后进入“文章”，点击“发布文章”。
2. 填写标题和摘要，选择分类。
3. 按需要关联 FIRE 路径或上传封面图。
4. 使用编辑器撰写正文；内容较长时可以先保存草稿。
5. 完成后提交文章。

源文档记录的限制如下，实际以当前页面提示为准：

| 内容 | 要求 |
| --- | --- |
| 标题 | 5–30 字 |
| 摘要 | 最多 100 字 |
| 正文 | 去除格式标签后至少 20 字 |
| 分类 | 必选 |
| FIRE 路径、封面 | 选填 |
| 封面图片 | 支持 JPEG、PNG、GIF、WebP，单张不超过 5 MB，按 16:9 裁剪 |

在“我的文章”中可以按已提交和草稿查看内容，也可以搜索、编辑、提交审核或删除。删除通常不可恢复。

### 发布社区帖子

1. 登录后进入“社区”，点击“发布帖子”。
2. 填写标题并选择板块。
3. 按需要填写标签，最多 5 个。
4. 写下问题、经验或讨论内容。
5. 保存草稿或提交审核。

帖子标题为 5–50 字，正文去除格式标签后至少 20 字，必须选择板块。编辑已发布内容后通常需要重新审核，审核通过前可能暂时不在公开列表中显示。

### 审核状态

统一的处理方式：

1. 进入对应的“我的文章”“我的帖子”等页面。
2. 查看已发布、审核中、草稿或已驳回状态。
3. 如果被驳回，阅读页面显示的原因。
4. 修改内容后重新提交。

“提交成功”通常表示已提交审核，不等于已经立即公开展示。不要因为等待审核而重复提交。

## 评论、点赞与收藏

在文章或帖子详情页可以点赞、收藏或发表评论。评论不能为空，提交后也需要审核。

个人中心的“我的评论”可以搜索、编辑、删除自己的评论并查看审核状态。编辑后的评论会重新进入审核。

“我的收藏”目前主要收纳文章、任务和社区帖子。文章详情页支持取消收藏；其他内容的取消状态以当前页面实际提供的操作和收藏列表为准。

## FIRE 路径

1. 进入“FIRE 路径”列表，点击路径卡片查看详情和关联文章。
2. 登录后点击“关注”记录正在关注的路径，再次点击可取消关注。
3. 如需申请新路径，填写路径名称、口号和路径说明；预期资产区间为选填。

申请提交后需要等待审核，审核结果通过站内通知告知。当前用户端没有独立的申请记录、撤回或编辑申请页面，提交前应认真检查内容。

## 个人资料与隐私

从右上角头像进入“我的主页”，再进入“我的信息”，可以设置头像、昵称、城市、个人网站、个人简介、FIRE 路径、实践开始日期、主要收入来源、月均支出和资料公开状态。

源文档记录的限制包括：

- 昵称 2–20 字且需要全站唯一。
- 个人简介最多 200 字。
- 用户名和邮箱为只读字段。
- 个人网站需要是有效的 `http://` 或 `https://` 地址。
- 月均支出不能为负数。

打开“资料公开”后，他人可能看到简介、城市、网站、FIRE 路径、实践日期和财务信息。公开前请确认隐私范围；邮箱和手机号不应作为公开资料展示。

## 通知、意见箱与投诉

- 通知铃铛可以打开最近通知，“查看全部”进入通知中心。
- 意见箱用于功能建议和 Bug 反馈，应说明页面、操作步骤、实际结果、期望结果和发生时间。
- 任务或技能的具体违规行为，应在对应详情页发起投诉，并在“我的投诉”查看状态。
- 不要在意见箱、投诉、文章、帖子或评论中填写密码、验证码、身份证号、银行卡号等敏感信息。

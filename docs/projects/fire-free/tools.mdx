# 工具箱

源文档显示，工具箱当前开放 FIRE 计算器；支出计算、被动收入计算、安全提取率、CoastFIRE 和进度追踪等工具仍处于规划中。

## 使用 FIRE 计算器

1. 进入“工具箱”，点击 FIRE 计算器。
2. 填写当前年龄、目标年龄、当前资产、每月投资、月支出和年化收益率等页面要求的参数。
3. 查看即时生成的 FIRE 目标金额、所需被动收入、当前进度、预计达成年龄和资产增长曲线。

## 估算方式

源文档记录的固定估算方式为：

- 目标金额按月支出、4% 安全提取率和 12 个月计算；
- 资产按年化收益率和每年追加投资进行模拟。

## 使用限制

- 结果会受到输入准确性、收益率假设、市场波动、通胀、税费、债务、社保、汇率和家庭责任等因素影响。
- 计算器不会自动保存方案、历史记录或同步到个人资料。
- 当前不支持导出图片或 PDF；离开页面前请自行记录关键输入和结果。
- 结果仅供个人思考，不能替代完整的财务、税务、保险或投资分析。

请根据自身情况独立判断，并在作出重大财务决定前咨询专业人士。

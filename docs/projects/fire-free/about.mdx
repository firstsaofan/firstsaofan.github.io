# 关于本站

FIRE自由 是一个开放的多元 FIRE 生活方式内容与实践平台。Slogan：不止一种 FIRE，找到属于你的自由。

全部正式文档无需登录即可查看。

## 我们是谁

本站由个人运营，运营者为自然人，非企业法人、非公司。运营者本身正在实践 FIRE 与兼职 FIRE，本站既是这个过程的记录，也是给同路人用的工具。

这不是一家公司。我们没有融资、没有股东、没有市场团队，也不向任何人收费。服务器的日常成本由原生赞助位与个人承担。如果您觉得这里有用，那就够了。

## 我们想解决什么问题

FIRE 这个词火了之后，涌进来的是两种声音：一种是「FIRE 是骗局、不可能」的否定，一种是「照这个方法做你也能财务自由」的成功学。两者都不是本站想提供的。

本站想做的是第三件事：把不同路径的真实实践摆出来，让人自己判断哪条适合自己。通往财务自由的路不止一条，没有唯一正确的答案，只有不同的约束条件。

所以本站的第一条产品原则是：**不定义唯一 FIRE。**

## 我们相信什么

1. **实践优先，鼓励真实经验。** 一份真实的、失败的、有具体数字的复盘，比十篇「十步实现财务自由」有用得多。
2. **多路径共存。** LeanFIRE、CoastFIRE、BaristaFIRE、RegularFIRE、FatFIRE、PartFIRE、数字游民 FIRE 都成立，没有高下之分。
3. **路径自治，平台治理。** 用户可以申请创建新路径；路径怎么用由用户决定，平台只负责不越界。
4. **用户既消费内容，也建设内容。** 地区数据、文章、经验帖、技能名片，都是用户建的。
5. **平台不介入交易。** 任务大厅和技能市场是信息板，不是交易所。
6. **数据可以被质疑。** 地图上的每个数字都标了来源、采集时间和统计口径，您可以核，也可以纠。

## 我们不做什么

这些是明确的边界，写在这里是为了让您知道本站不会提供什么：

| 不做 | 原因 |
| --- | --- |
| 支付与资金托管 | 需要牌照与资金池，法律和运营成本高 |
| 担保与仲裁 | 平台不承担用户间交易纠纷的责任 |
| 站内即时通讯 | 保持轻量，联系方式由用户自行提供 |
| 兼职撮合与招聘 | 任务仅作委托信息公告板，不做撮合、支付与担保 |
| 积分、信誉分、段位 | 只提供展示性的轻量等级与管理员授予头衔，不设兑换权益 |
| 城市排名与推荐榜 | 地图只显示「是否收录」和「是否命中你的筛选条件」 |
| 向用户收费 | 非营利，赞助仅用于覆盖服务器等基础成本 |
| 侵入式广告 | 不接追踪型广告，只做原生赞助位曝光 |

如果您期待的是「平台帮我担保」「平台告诉我买什么」「平台给我排名」，那本站不是您要找的地方。

## 内容从哪来

请注意区分三类内容，它们可信度不同：

**官方内容（运营者发布）**：本文档、[平台规则](./platform-rules.mdx)、[免责声明](./disclaimer.mdx)、使用教程、常见 QA、路径释义。反映的是平台的规则和口径。

**用户经验（用户发布）**：地区经验帖、社区帖子、文章。属于非官方信息，由用户自行负责，可能有错、可能过时、可能带有个人偏见。

**客观数据（含来源标注）**：地图中的房租、房价、气温、空气等指标，每条都附来源名称、来源类型、采集时间、统计口径。这是本站可信度最高的部分，但需要注意：

- 不同来源的统计口径可能不同，数字之间可能有差异；
- 「待完善」不等于 0，只表示本站暂时没有该字段；
- 数据会过期，作出租房、购房、迁居决定前请自行核实。

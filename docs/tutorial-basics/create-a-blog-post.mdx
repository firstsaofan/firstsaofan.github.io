# 创建博客文章

Docusaurus 会为每篇博客文章创建一个页面，同时提供**博客索引页**、**标签系统**和 **RSS** 订阅源。

## 创建第一篇文章

在 `blog/2021-02-28-greetings.md` 中创建文件：

```md title="blog/2021-02-28-greetings.md"
---
slug: greetings
title: 你好！
authors:
  - name: Joel Marcey
    title: Docusaurus 1 联合创作者
    url: https://github.com/JoelMarcey
    image_url: https://github.com/JoelMarcey.png
  - name: Sébastien Lorber
    title: Docusaurus 维护者
    url: https://sebastienlorber.com
    image_url: https://github.com/slorber.png
tags: [greetings]
---

恭喜你完成了第一篇文章！

可以继续修改这篇文章，直到内容符合你的需要。
```

现在可以访问 [http://localhost:3000/blog/greetings](http://localhost:3000/blog/greetings) 查看新博客文章。

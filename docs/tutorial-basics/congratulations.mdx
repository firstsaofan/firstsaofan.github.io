# 恭喜你！

你已经学习了 **Docusaurus 基础**，并完成了一些**初始模板修改**。

Docusaurus 还能提供更多能力！

还有 5 分钟吗？可以继续了解 **[版本管理](../tutorial-extras/manage-docs-versions.mdx)** 和 **[国际化](../tutorial-extras/translate-your-site.mdx)**。

本教程中还有不清楚或有问题的地方？欢迎[反馈问题](https://github.com/facebook/docusaurus/discussions/4610)。

## 接下来可以做什么

- 阅读 [Docusaurus 官方文档](https://docusaurus.io/)
- 使用 [`docusaurus.config.js`](https://docusaurus.io/docs/api/docusaurus-config) 修改站点配置
- 使用 [`themeConfig`](https://docusaurus.io/docs/api/themes/configuration) 添加导航栏和页脚项目
- 添加自定义[设计和布局](https://docusaurus.io/docs/styling-layout)
- 添加[搜索栏](https://docusaurus.io/docs/search)
- 在 [Docusaurus 案例展示](https://docusaurus.io/showcase)中寻找灵感
- 参与 [Docusaurus 社区](https://docusaurus.io/community/support)
